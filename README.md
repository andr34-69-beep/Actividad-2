## 📖 Conceptos fundamentales

- **Git:** permite llevar un historial de los cambios realizados en los archivos de un proyecto.
- **GitHub:** permite alojar repositorios en línea, compartir proyectos y colaborar con otras personas.
- **Repositorio:** espacio donde se almacenan los archivos y el historial de un proyecto.
- **Commit:** registro de un conjunto de cambios realizados.
- **Rama (*branch*):** línea de trabajo independiente dentro de un repositorio.
- **Repositorio remoto:** versión del repositorio alojada en una plataforma como GitHub.

---

## ⌨️ Comandos básicos de Git

| Comando | Función |
|---|---|
| `git init` | Inicializa un repositorio local. |
| `git status` | Muestra el estado de los archivos. |
| `git add .` | Prepara los cambios para el siguiente commit. |
| `git commit -m "mensaje"` | Registra los cambios preparados. |
| `git log` | Muestra el historial de commits. |
| `git clone URL` | Clona un repositorio remoto. |
| `git push` | Envía los commits al repositorio remoto. |
| `git pull` | Obtiene e integra cambios del repositorio remoto. |

> 💡 Estos comandos son una guía de referencia. Los que efectivamente utilice dependerán de las instrucciones de la actividad.
